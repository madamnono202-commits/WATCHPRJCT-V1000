## 2. Word Count & SEO Specifications

### 2.1 Word Count by Page Type

| Page Type | Target Word Count | Rationale |
|---|---|---|
| Homepage | 800-1,200 | Enough for SEO value + section intros; most content is navigational cards/links |
| Occasion Landing | 3,000-4,500 | Long-form guide with 8-12 product blocks + buying guide + FAQ (pillar content) |
| Budget Landing | 3,000-4,000 | Roundup format with 10-15 product blocks + intro + buying tips |
| Recipient Landing | 2,500-3,500 | Similar to occasion but with persona-focused framing |
| Brand Spotlight | 2,000-3,000 | Brand overview + 5-8 top picks + brand history/trust section |
| Single Review | 1,500-2,500 | Deep-dive review with specs, pros/cons, gift-worthiness analysis |
| Comparison | 2,000-3,000 | Side-by-side analysis, specs table, category winners, verdict |
| Blog Post | 1,500-2,500 | Educational/informational content, varies by topic complexity |
| Gift Finder Quiz | 300-500 | Minimal copy; UI-driven (questions, options, micro-copy) |
| Quiz Results | 400-600 | Dynamic; 3 product recommendations with brief descriptions |
| Static (About) | 500-800 | Brand story, mission, trust signals |
| Static (Contact) | 200-300 | Contact form + basic info |
| Static (Privacy/Terms) | 1,000-2,000 | Legal boilerplate, comprehensive but standard |
| Static (Affiliate Disclosure) | 300-500 | FTC-compliant disclosure, clear and concise |

## 3. Content Briefs (Per Page)

> Each brief below provides enough detail for a writer or AI to generate a complete first draft. Briefs are organized by page type/template. Each brief includes: sections required, tone notes, image placeholders, CTA placement, and affiliate link placeholders.

### 3.1 Global Content Guidelines

**Tone:** Friendly gift-guide blogger + expert authority. Write as if advising a friend who asked "What watch should I get him?" Use "you" and "your" frequently. Be warm but knowledgeable.

**Voice Rules:**
- First person plural ("we tested," "our pick," "we recommend")
- Address the buyer directly ("your husband," "your dad," "the man in your life")
- Avoid jargon unless explained ("automatic movement — meaning it winds itself as he wears it")
- Use gift-framing language ("imagine his face when he opens this," "a gift he'll wear every day")
- Never use aggressive sales language ("BUY NOW!!!" = bad, "Check Price on Amazon" = good)

**CTA Text Options (use consistently):**
- Primary: `[Check Price on Amazon →]` — links to `{{AFFILIATE_LINK_AMAZON}}`
- Alt Primary: `[See Best Deal →]` — links to `{{AFFILIATE_LINK_BEST}}`
- Secondary: `[Read Full Review →]` — links to internal review page
- Tertiary: `[Compare with [Watch B] →]` — links to internal comparison page

**Image Placeholder Format:**
- Hero: `{{HERO_IMAGE: description}}`
- Product: `{{PRODUCT_IMAGE: Brand Model — white background, front-facing, high-res}}`
- Lifestyle: `{{LIFESTYLE_IMAGE: description}}`
- Blog: `{{BLOG_IMAGE: description}}`

**Affiliate Link Placeholder Format:**
- `{{AFFILIATE_LINK_AMAZON: Brand Model}}` — Amazon Associates link
- `{{AFFILIATE_LINK_BRAND: Brand Model}}` — Direct brand affiliate link
- `{{AFFILIATE_LINK_BEST: Brand Model}}` — Best available deal link

## Appendix: Content Checklist Per Page

Use this checklist before publishing any page:

- [ ] H1 contains primary target keyword
- [ ] Meta title is under 60 characters and contains primary keyword
- [ ] Meta description is under 160 characters and contains primary keyword + CTA language
- [ ] All H2s are descriptive and contain secondary/related keywords naturally
- [ ] Word count meets minimum for page type
- [ ] At least 3 internal links to other WristNerd pages
- [ ] At least 1 affiliate CTA visible above the fold (on product pages)
- [ ] All images have descriptive alt text containing relevant keywords
- [ ] All affiliate links use `rel="nofollow sponsored"` attribute
- [ ] Schema markup is implemented (correct type per page)
- [ ] Breadcrumbs are correct and schema-marked
- [ ] Pros/Cons included for every product (on product pages)
- [ ] Gift-Worthiness Score included (on review pages)
- [ ] FAQ section included with FAQPage schema (on guide/review pages)
- [ ] Email signup form is present (footer + inline on long pages)
- [ ] Mobile layout is verified (CTAs are tappable, images responsive, tables scroll)
- [ ] Page loads under 2.5 seconds (LCP)
- [ ] Canonical URL is self-referencing
- [ ] Open Graph and Twitter Card meta tags are set
- [ ] Affiliate disclosure link is accessible from the page
